# 定点：安卓免 Root 模拟定位

面向 Android 15，最低支持 Android 12。输入固定的 GPS 经纬度，向系统 `gps`、`network`、`fused` 测试定位来源持续注入位置；每个来源成功后才显示为已注入。无需 Root、无需解锁或清空手机。无网络权限、广告、账号及第三方运行库。

## 安装和首次使用

1. 把 `dist/fixed-location-1.0.1.apk` 传到自己的安卓手机，允许用于打开它的文件管理器安装该应用。
2. 在“设置 → 关于手机”中找到版本号并连续点击，开启开发者选项（不同品牌入口不同）。
3. 在开发者选项中找到“选择模拟位置信息应用”，选择 **定点**。安装后仍未列出时退出设置再进入。
4. 打开手机系统定位，打开定点并输入 **WGS84 纬度、经度**。
5. 点击“开始模拟定位”，允许定位权限；建议允许通知，以便在通知栏查看运行状态和停止。
6. 看到“正在提供模拟位置”和已注入的来源后，再切到微信测试。保持本应用后台运行；从最近任务中划掉会停止。
7. 点击应用或通知里的“停止模拟定位”撤销模拟来源，等待系统重新获取实际位置。

安装包是本地测试密钥签名的可安装 APK，不是应用商店发布版本。更新由同一项目的本地测试密钥签名；请保留 `.tooling/fixedlocation-test.p12`，不要公开或打进源码包。安装过程不需要 Root 或电脑连接手机。

## 坐标怎么填

- 纬度范围 `-90…90`，经度范围 `-180…180`，使用小数点；可以输入负数。
- 输入空白、非数字、无穷大或超范围坐标时不会启动。
- **需要 WGS84（GPS）坐标**。腾讯、高德地图常用 GCJ-02，百度地图常用 BD-09；这些坐标不能原样当成 GPS 坐标，否则会出现偏移。第一版不含地图搜索或坐标转换。
- 开始后不可修改输入；先停止、修改，再开始。不会自动开始或开机自启。

## 微信验收：需要在用户手机上执行

本地构建和核心逻辑测试不代表微信兼容性已通过。微信可以拒绝模拟位置；此应用不会隐藏系统模拟标记，不修改微信，不更改 IP、Wi-Fi 或基站信息，也没有直接调用 Google Play services 的融合模拟接口。

| 场景 | 操作 | 应记录的结果 |
|---|---|---|
| 系统基线 | 未运行模拟时让地图应用重新定位 | 记录实际位置 |
| 启动 | 开始模拟后，检查定点显示的注入来源 | 有成功来源，无失败状态 |
| 发送位置 | 微信聊天 → + → 位置 → 发送位置，观察重新定位后的当前位置 | 是否为目标位置；不要把手动选了一个地点误当作定位验证 |
| 共享实时位置 | 微信聊天 → + → 位置 → 共享实时位置 | 是否持续显示目标位置，是否报错或回到实际位置 |
| 后台 | 切到微信保持共享约 3 分钟，然后回定点查看是否仍运行 | 记录是否被省电策略终止；必要时允许后台运行再复测 |
| 停止 | 在定点或通知中停止，等待微信/地图重新请求位置 | 是否恢复实际位置；旧缓存可能不会立即消失 |

测试微信共享需要自己的测试会话或知情同意的联系人，本项目不会自动发消息、发送位置或开启共享。

## 常见情况

- **提示选择模拟应用**：到开发者选项中手动选择定点，普通定位权限不能代替此步骤。
- **系统定位关闭或权限撤销**：应用会停止/报错。重新开启、回到应用点击开始。
- **已注入但微信位置不变**：记录机型、系统版本、微信版本、两个场景各自表现。可能与应用拒绝模拟、缓存或定位来源有关，不能仅凭本应用运行状态认定微信兼容。
- **后台更新中断**：系统省电、Doze 或厂商后台限制可能暂停/终止服务。前台服务不是绝对保活保证。
- **停止后仍旧位置**：等待重新定位；必要时取消开发者选项中的模拟应用或重启手机。
- **来源清理失败**：界面显示失败来源及处理提示。强制停止或系统直接杀进程时不能保证 `onDestroy()` 被调用；异常退出后请取消模拟应用或重启。
- 本应用不提供“所有应用通用”或“微信无法识别”的保证。

## 构建与测试

本项目自带 Windows 构建脚本，使用 Python 3.9+、JDK 17+（推荐 21/24）。不会修改全局环境变量或安装系统服务。第一次运行会从 Google 下载 Android SDK 35、Build Tools 35 和 platform-tools，校验官方仓库标出的 SHA-1 后解压到忽略的 `.tooling/`。

```powershell
# 可选：指定本机 JDK。脚本也会检查现有 JAVA_HOME / PATH。
$env:FIXEDLOCATION_JAVA_HOME = 'C:\path\to\jdk-21'
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出：`dist/fixed-location-1.0.1.apk`、`dist/SHA256SUMS.txt`、`dist/apk-info.txt`。密钥和 SDK 不包含在交付源码包中。

```powershell
# 仅运行不依赖手机和 Android SDK 的核心逻辑测试
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\test.ps1
# 已完成 SDK 初始化时直接构建
python .\tools\build.py
# 若已连接自己的测试手机，可先查看连接状态，再自行安装
.\.tooling\sdk\platform-tools\adb.exe devices
.\.tooling\sdk\platform-tools\adb.exe install -r .\dist\fixed-location-1.0.1.apk
```

也提供标准 Android Gradle 配置供 Android Studio 导入；需配置 SDK 和兼容 AGP 8.7.3 的 Gradle/JDK。已验证的打包路径是上面的 SDK 构建脚本，未声称 Gradle 构建已执行。

核心测试覆盖输入边界、首帧发送、部分来源失败提示、失败回滚、更新失败停止和清理异常。APK 编译、签名校验与 manifest 检查可在本机完成；界面、手机系统行为和微信兼容性需要真机验收。

当前 1.0.1 共 34 项核心断言通过，其中包括 Android 15 运行中撤销模拟定位授权时停止并显示清理警告，以及更新延迟和缓存分类的检查。详细记录见 `docs/verification-1.0.1.md`；旧版记录保留在 `docs/verification-2026-11-03.md`。源码包可运行 `python tools/package.py` 重新生成。

## 1.0.1 诊断版：地图位置回跳

可直接覆盖安装，签名与旧版相同，不需要卸载。新增每轮更新计数、最长更新间隔、各系统来源缓存的时间、模拟标记和目标相符情况。请为定点允许精确位置，才能进行可靠的缓存对比；这项授权用于诊断，不保证改变目标应用行为。

复现步骤：开始模拟 → 切到百度地图等待回跳 → 立刻切回定点 → 点击“复制运行诊断” → 把文本发到当前排查对话。复制内容包括设备与系统版本、目标坐标和诊断状态；不会自动发送。回读属于系统缓存，不代表目标应用采纳。

如果更新轮数持续增长、系统来源均是新鲜且相符的模拟位置，但目标应用仍显示实际位置，应进一步核对目标 SDK 的独立网络定位或过滤行为，不能认定只是后台权限不足。若最长间隔明显超过预期一秒或服务停止，再排查省电和后台限制。

这是诊断改进，目前没有在用户 ColorOS 手机上验证，不是已确认解决兼容性的保证。
