# Android 15 免 Root 模拟定位

用户已选择免 Root 方案；范围沿用已展示的最小方案。

- 平台：Android 12+，主要面向 Android 15；target/compile SDK 35。
- 单页中文界面，输入 WGS84 纬度和经度，保存上次输入；提供开始、停止、系统设置入口。
- 使用系统测试定位来源 GPS、network、fused，只有至少一个已成功注入时显示运行状态；显示具体来源。
- location 类型前台服务，每秒发送带当前时间、单调时间、精度的固定坐标；通知可停止。
- 前置条件：系统定位开启、定位权限、开发者选项选中本应用；通知权限可选，拒绝不阻断模拟。
- 输入非法、授权不足和运行失败均给出中文原因；部分来源失败不静默忽略；停止与销毁逐项清理来源。
- 不要求 Root，不修改微信，不绕过模拟定位识别，无网络权限；不保证微信接受位置，不支持路径移动。
- 微信发送位置和实时共享均需要在用户手机上验收；本地验证不冒充微信兼容性验证。
- 交付：源码、可重现构建脚本、签名测试 APK、中文安装及验收指南。

验证：坐标边界/非数值、注入生命周期/回滚/清理故障的纯 Java 测试；SDK 35 编译、APK 签名和 manifest 检查。
